AI 學習助教

把課程問題交給本機 AI，透過串流方式即時取得繁體中文解說，讓程式設計與課堂觀念更容易理解。

PythonuvOllamaStreaming

一、作品做了什麼

本作品是一個命令列 AI 學習助教。使用者輸入課程或程式設計問題後，Python 程式會呼叫本機 Ollama 模型，並以串流方式逐段顯示回答。

  • 以繁體中文回答，適合初學者閱讀。
  • 回答盡量包含結論、步驟與簡短範例。
  • 使用者可連續提問，輸入 q 結束程式。
  • 使用本機模型，不需要雲端 API 金鑰。

二、使用工具與技術

  • Python：主要程式語言。
  • uv：管理 Python 套件與執行環境。
  • Ollama：在本機執行大型語言模型。
  • Streaming：設定 stream=True，逐段讀取模型輸出並即時顯示。
  • GitHub Actions：自動將 docs/ 部署到 GitHub Pages。

三、如何執行

  1. 安裝 Python 3.10+、uv 與 Ollama。
  2. 下載模型：ollama pull qwen2.5:3b。
  3. 複製專案並安裝依賴：uv sync。
  4. 複製 .env.example 為 .env，依需求設定模型名稱。
  5. 執行：uv run study-assistant。

四、執行結果

以下為示意畫面，實際回答會依模型版本與提問內容不同。

使用者：Python 的 list 和 tuple 有什麼差別？
AI 助教：簡單來說，list（串列）可以修改，tuple（元組）建立後不能修改。list 使用中括號，例如 [1, 2, 3]；tuple 使用小括號，例如 (1, 2, 3)。需要新增或修改資料時通常使用 list；資料固定時可考慮 tuple。

  • 工具：Ollama 與 Python ollama 套件。
  • 使用位置：src/ai_study_assistant/main.py 的 ask_ollama() 函式。
